# Group Chat Setup Guide

To enable the bot to work in group chats, you need to disable Privacy Mode in BotFather.

## Steps

1.  Open Telegram and search for **@BotFather**
2.  Send the command: `/setprivacy`
3.  Select your bot from the list
4.  Choose **Disable**

## What This Does

By default, bots in groups only see:
- Messages that mention the bot (@botname)
- Commands (/command)

Disabling Privacy Mode allows the bot to see **all messages** in the group, which is necessary for automatic transcription of voice messages.

## Adding Bot to a Group

1.  Open your group chat
2.  Tap the group name → "Add Members"
3.  Search for your bot and add it
4.  The bot will now automatically transcribe all voice and video messages!

## Features in Groups

- ✅ Automatic transcription of all voice/video messages
- ✅ Bot replies to the original message
- ✅ Summarize button works per message
- ✅ Localized messages based on sender's language
