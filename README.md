# Telegram Voice & Video Transcription Bot

This bot transcribes voice and video notes using Google Gemini.

## Setup Instructions (What you need to do)

### 1. Get a Telegram Bot Token
1.  Open Telegram and search for **@BotFather**.
2.  Send the command `/newbot`.
3.  Name your bot and give it a username (must end in `bot`).
4.  **Copy the API Token** it gives you.
5.  I have already added this to your `.env` file, but if you ever need to change it, that's where it goes.

### 2. Google Cloud / Gemini API
- You already provided the API Key, so this is set up!

## Usage
- The bot is running on your machine.
- Just send it a **Voice Message** or **Video Note**.
- It will reply with the text transcription.

## Troubleshooting
- If the bot stops working, check the terminal for errors.
- If you see "Unsupported media type", try sending a standard voice note.
